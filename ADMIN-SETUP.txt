YONO GAMES Data — Master Admin setup

1) Put index.html, admin.html, apps.json, recovery.json and site-config.json in the same GitHub Pages repository.
2) Open admin.html. Unlock with the passcode you configured for this project.
3) Enter GitHub username, repository, branch and a GitHub Personal Access Token. Keep the token only in the browser; never add it to index.html.
4) Click Verify, then Load Current Apps.
5) Add/edit/remove/recover an app. Click Atomic Publish. The app data is published in one Git commit.
6) For shared live analytics, create a Google Sheet and deploy stats.gs as a Google Apps Script Web App. Store SHEET_ID and ADMIN_KEY in Script Properties. Set access so the public site can POST events and the admin can GET them with the private key.
7) Copy the deployed Web App URL into Tracking endpoint and the private ADMIN_KEY into Tracking admin key, then click Save & Publish Tracking.
8) The public index records page_view, app_view and download_click events. The dashboard shows today, daily, monthly and five-month summaries plus anonymous browser-ID/app activity.

Important: the browser ID is anonymous and does not identify a person's real identity. A static site cannot securely know a person's real identity or guarantee an actual file download after an external link opens; the dashboard measures website/app view and download-button click events.
